# 工作台完整流程交互原型

本目录是**设计稿，全部内容与结果为合成**，不连接产品宿主、数据库、文件工具或模型。不是另一套可执行Agent界面。页面顶部浅绿色控制条只用于切换样例，不属于产品UI；输入任意文字也只进入合成状态，不理解或执行该文字。

打开 [index.html](index.html) 即可使用；无安装、构建和外部资源。若浏览器限制本地脚本，从仓库根运行 `python3 -m http.server 4318 --bind 127.0.0.1 --directory docs/design/workbench-prototype`，打开本机 `http://127.0.0.1:4318/`。从其他目录运行时，将 `--directory` 指向本目录。此服务只展示本目录；使用后Ctrl+C关闭。

## 本轮方案

- **导航**：新建明确选择目标目录，当前会话目录在顶部独立可查；同名历史会话补父目录。去掉常驻ID、数量、目录表单与健康连接行。新建后从标题改名，没有隐藏预命名草稿。
- **阅读**：正文/输入同轴，正常工具是一条可展开摘要，细节仍归原操作；不假装当前协议已有正文/工具真实穿插。
- **当前审批**：固定在输入区上方，目标、关键影响、拒绝/仅本次允许集中。长写入内容进入只读详情；处理后回到输入，历史仅保留原操作结果。取消顶部待审批跳转按钮。
- **输入**：权限直接显示当前值，悬停/聚焦“更改权限”，保存未确认在关闭面板后仍可见；模型只作信息入口。发送与排队语义明确，草稿按会话隔离；停止仍有一个顶部可达控件，不因文档覆盖消失。
- **文档**：Chat的文件入口打开右侧正文；标题栏只保留文件选择、复制、版本来源与关闭。无常驻版本总表、无260px正文盒、无额外阅读/源文模式工具带。
- **窄窗**：文档切换为内容带内的专注预览，顶部操作保留；有待批时从预览返回输入区处理，不复制一套审批。更窄时导航成为可退出的覆盖层。

详细空间、父子控件、参数与例外统一在[规格树](../../ssot/ui/README.md)。本页是原型使用/取舍说明，不另立布局权威；正式产品后续实现见[实现报告](../../validation/ui-workflow-2026-10-08.md)；本原型仍是独立合成设计稿，不随产品状态变化冒充执行证据。

## 一次完整演练

1. 点“新建会话”，选示例目录；输入任务，点发送。
2. 人工审批时，操作在输入区上方出现。可查看内容，再拒绝或仅本次允许；拒绝无文档。
3. 允许后显示执行中。顶部设计控制条“模拟结果到达”代表本次合成结果到达，不调用工具。运行时输入下一条会加入队列，可取消首条。
4. 从Chat打开文档，读长正文、切换示例文档、查看版本/来源，再关闭返回；“文件已改变”场景不会展示旧正文冒充成功。
5. “停止”只进入等待结算；再按设计控制条模拟清理完成。连接中断场景先重连到未知，再检查已有结果，不展示自动重发。
6. 场景选择可直接切到权限未确认、断线、未知、长内容。切会话保留各自草稿；左右分隔条可拖动或用左右方向键调宽，Home复位。

原型只演示单个任务段与少量合成会话；不模拟完整历史数据库、游标、多个审批排队、宿主事务或持久恢复。不同场景切换是设计控制，不是产品状态迁移证明。权限成功/核验/结算均是手动合成结果。复制使用浏览器剪贴板，拒绝时显示失败；不代表已接入Electron产品复制窄桥。

## 文档自动打开A/B

| 方案 | 演练方法 | 取舍 |
|---|---|---|
| A · 前台首次自动 | 选择A→新会话发送→允许→模拟结果 | 宽窗第一次前台新登记可直接展开，用户正在旧记录阅读、已手动选文档或关闭时不抢开。帮助发现结果，但需要可靠的新登记/前台身份 |
| B · 仅点击 | 选择B→重复同一路径→点击Chat文件 | 干扰更少；首次用户需要发现文件入口。窄窗优先此行为，避免突然遮住会话 |

设计建议是宽窗满足条件时A、窄窗B；产品缺少可靠的新登记判别时先用B。历史补页/重连不是新文档到达，不能自动打开。原型的“文档已生成”场景直接打开文档是为了审阅状态，不代表所有启动默认三栏。A/B只是设计控制，不增加产品配置开关或展示授权。

## 设计自检与限制

当前对象可从会话标题、必要目录与文件名辨识；输入和决定位于稳定位置。正常页不平铺执行ID/哈希/配置说明，异常仍可见。图标都有名称，但熟悉度仍需用户体验确认；关键批准/拒绝/停止保留文字。导航品牌和底部身份样例不意味着新增账户功能。

本轮将截图、DOM状态检查、键盘事件与实际产品测试分开记录。原型尚未验证真实IME、VoiceOver、完整多审批、长Bash风险、多错误同时占位、产品滚动锚点和动画观感；静态原型的全部按钮成功不等于真实产品链路通过。
