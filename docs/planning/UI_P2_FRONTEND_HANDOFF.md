## 已接入的展示链路

- 复用 RunHistory、ApprovalList、ArtifactPanel 与既有产品命令身份/确认重试。右栏收起、三档宽度、草稿/焦点、成果状态和原生 Session 所有权不变。
- Renderer 不再调用全量 thread()。历史、工具记录、成果分别请求正式 historyPage / operationPage / artifactPage；每次最多请求8条，实际返回还受宿主256000字节限制。提供“加载更早记录/工具记录”和“加载更多成果”。
- ThreadActivity 独立轮询，提供当前执行、审批与工作区状态；历史加载慢或失败不阻断当前审批/停止。失效工作区不能发送。
- 页游标不解析、不当事件序号。首次读取使用各页最早的 snapshotSeq，之后只推进到实际收到的最后事件；128条批次继续补读，不以较新的活动快照跳过事件。
- 普通事件按Run/工具/成果定向读取；新Run只补首屏到已知头部，旧尾游标不变。未知事件或重连从新首屏重建到已浏览最旧记录。加载旧页前记录滚动锚点。切换会话保留已浏览深度和位置，过期请求结果不能发布到当前会话。
- 页错误保留已读内容并给出重试；重试只读，不重新执行工具。成果只有按需 preview 才读文件，标签仍表示上次核验。

## 验证和边界

[分页组合证据](../validation/ui-p2-pages-2026-09-30.md) 区分合成显示故障、实际SQLite/IPC分页、实际Pi Worker审批/取消和离线Provider回归。60条持久合成Run超过旧1.2 MB全量响应上限，可由真实Electron逐页读取；不冒充60次模型调用。

新增的historyEntry只返回既有HistoryItem安全投影；不新增数据库写入器、通用缓存框架或第二套Session树。ThreadPages只是Renderer的已加载产品展示范围。没有虚拟列表/内存总量上限；加载越多DOM越大，普通正文更新不再重读已加载范围；home会话目录及原生Session全部正文尚未分页。窗口重启不保存滚动位置。Windows、PTY、真实模型桌面人工体验和生产发行未验证。

2026-09-30已按用户授权与后端完整分支合入develop，见 [集成记录](../validation/ui-p2-merged-2026-09-30.md)。当前工作与后续人工使用顺序只以NEXT_STEPS顶部为准，不把限定组合验收提升为UI-01/02、ART-01全部完成。
