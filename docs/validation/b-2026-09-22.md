## 已验证行为

| 范围 | 实际断言与证据性质 |
|---|---|
| 命令与幂等 | 未知字段、访问器、函数、越权路径/绑定和未开放意图拒绝；字段顺序变化不影响幂等，重开后同请求复用响应，不同内容冲突 |
| 持久事务 | 注入真实 SQLite trigger 故障，Run/事件/请求回滚；失败没有派发；状态和产品事件在同一事务提交 |
| 单写准入 | 多个真实连接、直接 SQL 唯一约束负向测试；审批中、取消清理中及 unknown 均不释放全局名额；队列不双派发 |
| 批准与操作 | 摘要/目标/期限/绑定不变；未批准、拒绝、过期或已领取不能执行；结果 unknown 立即使绑定失效，原操作的迟到事实仍可对账 |
| 取消/恢复 | 合成活跃操作结果未落定或 host/Pi 清理未确认时拒绝终结；副作用成功仍记成功，不虚构回滚；重开后显式模拟崩溃恢复为 unknown，不重放，清理/对账后才放行 |
| 身份 | 同 Run Session 变更和同 Session 相邻 Run 使用新身份；旧观察不写新 Run；真实 Pi Runtime newSession 后重新订阅；旧操作结果归原 operation |
| 快照/事件 | snapshot 与 cursor 一致；窗口事件从持久表补齐；跨 128 条批次、Run seq、去重、反订阅、重入、监听异常恢复与另一连接 poll；重放不执行任务 |
| 原生历史 | 实际 Pi Session 保存/关闭/重开内容一致；产品库只存原生引用，产品状态修改不改变 Session 文件；SQLite 无原生消息内容，UI 投影无原生文件路径 |
| 成果 | 实际 Pi write 经持久批准生成文件；拒绝时文件不存在且 write_start 零增加；成果关联原操作、精确目标、真实内容 hash；复制同字节到其他路径也拒绝 |
| 预览/版本 | 真实文件缺失/越界/链接/大文件/无效 UTF-8 拒绝；外部修改返回 changed，不能冒领旧操作；新操作生成新版本；HTML 字样只按纯文本返回 |

核心 17 项使用真实 ProductCore/SQLite/文件系统，Worker 完成、清理与崩溃输入明确为合成。SDK 5 项中 4 项使用实际 Pi Session/工具/Runtime，1 项是明确标记的未来事件合成投影。`agent_end` 仅为 activity，`agent_settled` 也只是 idle 观察，均不单独完成产品 Run。实际 0.87.0 事件来源缺省为 null；兼容合成 source.type 的负向测试不冒充真实上游事件。
