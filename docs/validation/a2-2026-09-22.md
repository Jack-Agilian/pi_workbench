## 复用与最小新增

复用 Pi 公开 `create*ToolDefinition`、`defineTool`、`createAgentSession`、`validateToolArguments`、MIME helper 和 `createLocalBashOperations`。保留完整工具定义、同名 schema、prepareArguments、constrainedSampling、executionMode 及 prompt/render 元数据。编辑匹配、兼容旧输入、BOM/换行、diff/patch、文件队列和输出裁剪均由 Pi 实现。

新增 `tool-probe.ts` 和两份测试；既有隔离启动器增加显式 `--tools`/`--shell` 模式，既有空资源/凭据 services 抽成共享入口。没有新目录树、Harness、RunCoordinator、工具算法、Provider、技能解析器或包管理器。

每次调用捕获不可复用 operationId、固定 runtimeBindingId/runId/runtimeEpoch/workspaceRef、实际最终参数摘要和 deadline。批准结果绑定该 operation，参数以冻结快照执行，不能复用前一次批准。Operations 通过本次闭包核验路径、取消/有效期、批准文件版本、读版本与写入前版本；派生写入内容摘要单独记录。观察始终带原操作身份，已完成的迟到副作用不被当作回滚或新操作。

无模型驱动器在测试中显式调用一次公开 prepareArguments 和一次公开 validateToolArguments，再执行 Session 活动注册表中的工具。它不是模型触发工具的 Agent Loop 测试；没有用合成模型响应冒充真实 fixture。工具测试中的 BashOperations 故障、输出和等待均标明 SYNTHETIC；独立 Shell 测试使用真实本机进程。
