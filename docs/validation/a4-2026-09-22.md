## 实际断言

| 范围 | 结果 |
|---|---|
| 公开入口/显式存储 | 根 ESM 导出、类型和类方法区分；临时 agentDir 内故意无效 auth/models 文件保持原样，注入存储不读这些文件；内置模型目录离线可查，空凭据不可用 |
| API key 生命周期 | 合成登录写入 Pi store；runtime key 优先但不改底层 store；移除 override 恢复原存储值；logout 清除两者，目录可用性一致 |
| 脱敏状态 | 原始名称、模型 ID/URL/headers、source 和错误均含合成 canary；投影只返回宿主白名单展示字段，失败状态不携带异常内容 |
| OAuth 配置/刷新 | 过期记录的 checkAuth/状态读取不刷新；8 个并发 getAuth 经 Pi 锁只刷新一次；失败保留原记录且不回退 API key |
| 竞争 | 活跃刷新期间 login/logout 最终获胜；旧刷新不覆盖新登录，不在注销后恢复旧凭据 |
| 取消 | 合成刷新已开始后 abort；调用方返回但 store 锁仍等待底层回调结束，迟到结果不持久化；活跃/排队登录取消后不写入、不执行已取消的排队登录，后续队列可继续 |
| 提交后失败 | login/logout/setRuntimeApiKey/removeRuntimeApiKey 四种变更均实际提交后触发目录故障；Pi 抛出 CredentialSynchronizationError，投影为 committed_needs_sync，变更不自动重试；公开离线 refresh 恢复一致性 |
| 存储故障 | 合成 store 在写入前或写入后拒绝均映射 unknown；断言真实存储内容区分两者，不根据普通异常假定回滚 |
| 目录/Session | 公共 modelsStore 缓存恢复及 Session 模型选择通过；tools/资源空，消息数为零，无 auth/models 文件落盘；旧刷新 publish 以 AbortError 被拒绝，不能覆盖新目录或已保存缓存 |

上述取消是**合成认证回调**的活跃取消，不是运行中真实模型取消；也不是仅 idle abort。没有调用 prompt/complete/stream、真实 OAuth 登录、远端目录、真实 Provider 或系统密钥库。
