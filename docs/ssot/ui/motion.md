# 开合、拖动与层级

ID：MOTION。归属：[规格树](README.md)。**目标规格，当前没有完整动效实现**。本轮复用已审读Impeccable的可中断/减弱动效思想，以下具体时间与状态机是项目设计选择，不冒充上游默认。

| 行为 | 目标属性/时间 | 必须保留的空间与交互 |
|---|---|---|
| 桌面侧栏收放 | 容器宽度0↔记忆宽，180ms，ease-out；内容不缩放，可裁切 | 主区同步取得/让出空间；不把字体横向拉伸；开合期间暂停拖宽，保留原宽度偏好 |
| 窄窗导航/成果覆盖 | 从所属边缘平移，180ms，ease-out；背景透明度120ms | 主会话布局宽度不变；覆盖层只遮本节点规定区域 |
| 并排成果开合 | 同侧栏宽度动效；不自动弹出 | 原正文锚点/草稿保留，焦点只随显式用户动作转移 |
| 气泡/选择面板 | 气泡悬停延迟400ms、键盘聚焦即时；面板淡入100ms，最多4px位移 | 不跟随轮询闪烁；交互面板不等同气泡；新开一层关闭同级旧层 |
| 拖动分隔条/连续调宽 | 0ms，实时反馈 | 不叠加缓动造成鼠标追赶；松开/失焦/取消结束，原键盘20px步长与复位保留 |
| 减少动态效果 | 空间动效0ms，移除位移；显隐和必要状态即时完成 | 保留相同最终布局、焦点和可达性，不依赖动画结束事件才能清理 |

## 生命周期与焦点

开合逻辑明确closed/opening/open/closing；连续反向点击从当前视觉位置转向最新目标，不排队重播。关闭请求被接受时，先将内部焦点移回有效触发点并使关闭内容不可交互；动画完成后移除/隐藏布局。开启时使内容可达：桌面非模态默认不抢焦点；模态覆盖将焦点送入关闭按钮或首个合理控件。动态中取消、卸载、切会话、窗口越断点均落到最后有效状态，不留下透明拦截层。

动画结束不能派发产品命令。宽度变化由既有滚动所有者维持阅读锚点/跟随最新；程序化布局滚动不当作用户新阅读意图。不要让每帧ResizeObserver反复重新定位。切断点、初始化和恢复存储偏好直接落位，不播放首次“滑入”。

## 层级与模态范围

按顺序：普通内容 → 局部sticky标题 → 分隔条 → 就地选择/说明面板 → 成果覆盖的背景与面板 → 窄窗导航背景与面板。提示气泡属于其触发面板内部，不跨越更高模态层。数值实现由共享样式持有，子组件不得各加9999。

成果覆盖限制在主区内容带，顶部审批/停止仍可用；不能给整个应用宣称aria-modal却留下顶部可操作。导航窄窗覆盖整个工作台，其打开期间主区不可交互，关闭/选择后返回合理入口；活动执行及审批数量在导航内有必要的可达提示或关闭路径，不能因折叠丢失任务。Escape先关闭最上层，不能同时关闭所有父层。模态圈定焦点，非模态不困住Tab。

## 验证

实际录屏/连续帧与交互检查：快速反向开合、拖动中失焦、开合时切会话/改断点、200%、低高度、长列表、阅读旧消息、减少动态效果。分别记录抖动/文本重排、焦点、遮罩、偏好和滚动；静态截图或等待180ms的测试不能单独证明动效质量。当前源码使用hidden直接显隐，不能标动效已通过。
