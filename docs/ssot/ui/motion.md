# 开合、拖动与层级

ID：MOTION。归属：[规格树](README.md)。v2采用一次布局切换、轻量出现的方案，取消v1“必须180ms宽度动画/四态自建生命周期”的要求。依据[逐控件审核](../../validation/ui-control-audit-2026-10-08.md)，截图/社区材料不能支持该精确时长。

| 行为 | v2实现 | 交互约束 |
|---|---|---|
| 并排导航/文档开合 | 宽度一次落位；手动打开可140ms淡入、最多6px位移；收起即时 | 不让中文每帧换行；阅读锚点由唯一现有所有者保存。产品仅出现轻动效；不宣称完整收放观感通过 |
| 窄窗导航/专注预览 | 即时切换，先验证退出与焦点；暂不增加滑动动画 | 不改变Chat原滚动宽度；顶部停止仍可达。需要动态改善再基于实际连续观察选择 |
| 气泡/选择面板 | 悬停约350ms，键盘即时；面板先即时显隐 | 时间是候选，不是社区标准。权限气泡可Escape关闭、可移入阅读；短提示不承载额外信息；不能存放失败原因 |
| 拖宽/连续调宽 | 0ms，实时跟随；键盘沿现有20px步长与复位 | 统一空间预算，拖动中夹紧有效范围；失焦/取消停止，不能动画追赶鼠标 |
| 减少动态效果 | 去掉淡入/位移/延迟，立即给最终布局 | 焦点与功能相同，不等待animationend才能完成清理 |

## 焦点、关闭与阅读

显式打开文档可以聚焦关闭/文档入口；自动展示不抢输入或阅读焦点。关闭先返回仍存在的Chat文档入口，入口不在已加载范围则回HEAD文档按钮，再隐藏。桌面导航关闭不把焦点留在已隐藏控件；窄窗选择会话后回主区。快速反向操作取最后选择，不排队播动画，不要求所有控件自建同一状态机。

目标是不在初次恢复、缩放、跨断点、拖动时播放出现动画；当前CSS出现动画未按触发来源细分，此项仍待实际观感核验；自动到达内容不反复闪动。保持草稿、选择及阅读位置，不能每帧ResizeObserver反复改scrollTop。展开与动画不触发模型或工具；显式打开文档依原安全边界重新核验，布局尺寸变化本身不核验。

## 层级所有权

普通内容 → 局部标题/分隔条 → 对象选择/信息面板 → 内容带专注预览 → 全工作台窄导航。一次仅最高层接收交互。右侧专注预览使CHAT不可交互，但HEAD保留导航和停止；不困住整个应用Tab。窄导航使WORK不可交互，圈定导航焦点，保留明确关闭入口。关闭导航恢复之前的文档选择，不擅自开新文档。

同级选择面板互斥，Escape只关闭最上层，返回触发器；不能一次按键同时关选择面板和文档。原型使用浏览器原生dialog验证关闭/焦点，并不决定产品必须使用原型的模态实现；本批产品采用React公开createPortal/useLayoutEffect薄封装浏览器原生dialog，复用原生模态和焦点；不自建弹层框架。

## 验证

宽窄/200%/低高度、快速反向、拖宽、长中文、阅读旧消息和减少动态效果分别检查。原型静态截图与DOM检查不能证明连续动画观感、真实IME或VoiceOver；产品宽度立即落位，出现时轻量淡入/位移；减少动态效果直接最终态。连续观感仍未验证。
