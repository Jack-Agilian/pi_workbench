# SHELL 工作台窗口

ID：SHELL。父：[规格树](../README.md)。子：[NAV](navigation.md)、[WORK](workspace/README.md)。职责是分配窗口空间与全局覆盖关系；不负责Run权限/工具执行。参数继承[共享尺寸](../foundations.md)，动效继承[共享规则](../motion.md)。

| 子空间 | 位置/尺寸 | 目的与限制 |
|---|---|---|
| NAV | 左侧全高、固定可调宽；收起后宽0 | 管理目录和会话；入口始终留在WORK顶部 |
| WORK | 右侧flex占余量、min-width:0、全高 | 承接标题、反馈和正文/成果，不产生整窗嵌套滚动 |
| 覆盖背景/分隔条 | 按动效文档指定所属范围与层级 | 拖宽和覆盖不能扩大业务权限，不能挡住错误后的恢复路径 |

默认两栏，文档显式打开；前台首次新登记的候选自动展示规则由ARTIFACTS持有，不能补页/重连自动打开。导航偏好全局本机记忆，成果开合沿用按会话的Renderer状态；不要把“按会话”误写成重启后持久化承诺。缩窗只限制当前可见宽度，不能覆盖用户记忆宽度。系统标题栏留给Electron/macOS，不在页面复制交通灯；将来改标题栏需独立核对拖动区与点击区，本轮无此改动。

源码：[renderer](../../../../apps/desktop/renderer.tsx)、[pane-layout](../../../../apps/desktop/pane-layout.ts)、[main](../../../../apps/desktop/main.ts)。现状：1320×900初始外框、820×640最小外框；已有可调栏宽及覆盖模式，收放直接hidden。差距：需统一父子空间预算和动效，不将目标写成已完成。

验收：默认/收起/成果展开；1320、实际并排预算两侧、760/759、820与200%组合；三栏总宽不溢出，主会话保底正确，恢复偏好无首帧闪动，无透明覆盖残留。尺寸与阅读/审批/输入一起测，不只看空页面。
