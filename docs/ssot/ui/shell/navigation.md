# NAV 导航侧栏

ID：NAV。父：[SHELL](README.md)。职责是找回/新建会话和选择目录，不展示执行诊断面板。宽度与开合继承共享规则；上下固定区＋中间目录列表占余量，只有列表常态滚动。内边距12，组间12；底部连接区不覆盖列表。

| 子节点 | 位置/空间 | 功能、默认与展开 |
|---|---|---|
| NAV.BRAND | 顶部32高，名称可省略但不挤关闭按钮 | 低权重品牌；窄窗右侧关闭图标命中框28 |
| NAV.WORKSPACE | 品牌下32高、整行 | 显示目录名＋下拉指示；完整路径按需可达，同名时补辨识；目录选择仍走宿主 |
| NAV.CREATE | 下一行36高，新建占余量，更多28宽 | 新建为明确动作；可选名称进入相邻面板，不常驻一整表单 |
| NAV.SEARCH | 新建下方32高 | 搜索会话/目录，清空入口；空结果不清空当前会话或执行 |
| NAV.FILTER | 搜索旁次要入口，展开宽不超侧栏可用宽 | 工作目录筛选移入按需区，选中条件有可见摘要及清除；不能隐藏当前过滤事实 |
| NAV.RESULTS | 列表前12号短行 | 最近创建/搜索结果及已加载数量，后续页用“+”；读取状态/失败恢复就近，不称全量计数 |
| NAV.LIST | 剩余高度，可滚动 | 主要为名称/选中/活动状态；分页在列表末，加载错误就近重试 |
| NAV.ROW | 列表项最小40高；主文本flex，次动作28 | 通常一行名＋必要辨识行；完整ID放详情。同名目录须可辨；改名入口悬停或focus-within出现，不能键盘不可达 |
| NAV.RENAME | 原行下就地展开，自动高度 | 草稿、确认/取消、冲突就近显示；不能挤掉当前执行定位入口 |
| NAV.CONNECTION | 底部最小28高 | 低权重本地连接状态；错误恢复动作由FEEDBACK拥有，避免重复按钮 |

空目录显示新建引导；加载保留已显示项；断线/创建未确认不得伪造新会话。当前/正在改名的会话在过滤后仍可辨识，不把保留行算入查询总数。窄窗选中或新建成功后关闭覆盖，焦点返回主区；名称面板关闭不能触发新建。

低高度允许侧栏整体滚动作为退路，不能固定列表最低高度把关闭/新建挤出窗口。拖宽不动画；收放按[动效规则](../motion.md)。收起不清搜索词、编辑草稿或活动状态。

源码：[thread-directory](../../../../apps/desktop/thread-directory.tsx)、[thread-navigation](../../../../apps/desktop/thread-navigation.tsx)、renderer、style.css。现状：上述功能已有；目录过滤选择器/改名按钮常驻，标题/短ID/次要说明仍较密集，需按目标重排。功能边界沿用[目录契约](../../thread-directory-contract.md)和[命名契约](../../thread-naming-contract.md)。

验收：0/1/75项、同名长中文/路径、无匹配、当前行在页外、改名冲突、重连；224/180宽及200%、键盘找入口；开合不丢草稿/搜索、不导致新Run。
