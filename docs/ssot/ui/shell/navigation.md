# NAV 导航侧栏

ID：NAV。父：[SHELL](README.md)。职责是找回/新建会话；目录选择属于新建动作，不展示执行诊断面板。宽度与开合继承共享规则；上下固定区＋中间目录列表占余量，只有列表常态滚动。内边距12，组间12；底部连接区不覆盖列表。

| 子节点 | 位置/空间 | 功能、默认与展开 |
|---|---|---|
| NAV.BRAND | 顶部32高，名称可省略但不挤关闭按钮 | 低权重品牌；窄窗右侧关闭图标命中框28 |
| NAV.WORKSPACE | 新建动作的目录面板中 | 明确“新会话的工作目录”，默认沿用已选目录；同名显示父路径，选择仍走宿主。不是当前Thread归属，不常驻第二条泛称目录 |
| NAV.CREATE | 品牌下32高、整行主动作 | 先确认新建目标目录，再创建并输入；可选名称仅在同一新建面板内明示，关闭后保留草稿；创建未确认时锁定原意图，重试同一次创建。创建后从标题/行改名。已确认的默认目录可在产品实现中减少一次选择，不取消目录可发现性 |
| NAV.SEARCH | 新建下方32高 | 搜索会话/目录，清空入口；空结果不清空当前会话或执行 |
| NAV.FILTER | 搜索旁次要入口，展开宽不超侧栏可用宽 | 工作目录筛选移入按需区，选中条件有可见摘要及清除；不能隐藏当前过滤事实 |
| NAV.RESULTS | 列表前12号短行 | 默认“会话”，查询时“搜索结果”；普通已加载计数放分页，不常驻。读取失败就近，不能伪称总数 |
| NAV.LIST | 剩余高度，可滚动 | 主要为名称/选中/活动状态；分页在列表末，加载错误就近重试 |
| NAV.ROW | 列表项最小40高；主文本flex，次动作28 | 通常一行名＋必要辨识行；完整ID放详情。同名/跨目录保留必要父路径；改名以HEAD标题为主，行入口悬停或focus-within出现，不能键盘不可达 |
| NAV.RENAME | 原行下就地展开，自动高度 | 草稿、确认/取消、冲突就近显示；不能挤掉当前执行定位入口 |
| NAV.CONNECTION | 底部最小28高 | 正常连接不单独常驻一行；异常可低权重提示，恢复动作只由FEEDBACK拥有。原型底部是身份样例，不是新账户系统 |

空目录显示新建引导；加载保留已显示项；断线/创建未确认不得伪造新会话。当前/正在改名的会话在过滤后仍可辨识，不把保留行算入查询总数。窄窗选中或新建成功后关闭覆盖，焦点返回主区；目录面板关闭不能触发新建。

低高度允许侧栏整体滚动作为退路，不能固定列表最低高度把关闭/新建挤出窗口。拖宽不动画；收放按[动效规则](../motion.md)。收起不清搜索词、编辑草稿或活动状态。

源码：[thread-directory](../../../../apps/desktop/thread-directory.tsx)、[thread-navigation](../../../../apps/desktop/thread-navigation.tsx)、renderer、style.css。现状：新建目录与可选名称已收拢；过滤展开、活动筛选可见，普通短ID/计数移除；标题委托既有行内改名，行入口悬停/聚焦出现。功能边界沿用[目录契约](../../thread-directory-contract.md)和[命名契约](../../thread-naming-contract.md)。

验收：0/1/75项、同名长中文/路径、无匹配、当前行在页外、改名冲突、重连；共享宽度的最小/最大及200%、键盘找入口；开合不丢草稿/搜索、不导致新Run。
