# PERMISSION 权限选择器

ID：PERMISSION。父：[COMPOSER](README.md)。职责是确认和改变**后续任务**模式；当前Run已固定权限不在这里改。

| 子节点 | 布局/大小 | 内容与交互 |
|---|---|---|
| PERMISSION.TRIGGER | 工具栏左侧，32高，宽随文字 | 仅“人工审批 ▾ / 自动审批 ▾ / 完全访问 ▾”；选中值常驻，不加“权限：” |
| PERMISSION.TIP | 触发点附近，小文本 | 悬停/聚焦“更改权限”，时序继承MOTION；不承载风险或按钮 |
| PERMISSION.PANEL | 优先向上、左沿对齐，宽320且不超过可用视口减24，内边距12 | 视口避让/高度受限时内部滚动；三个选项，不覆盖发送与必要错误 |
| PERMISSION.OPTION | 整行按钮，最小44高，名称13＋说明12 | 明确选中项、工作目录/网络范围、生效时机；完全访问影响在选择时可读，不做二次悬停 |
| PERMISSION.SAVE | 面板内原位置，自动高度 | 保存中、冲突、未确认、失败分别反馈；关闭面板不能宣称已保存，未确认在触发器附近仍可见 |

辅助技术名称同时表达当前值与更改用途；正确控件语义决定键盘行为，不能只加menu角色。优先已有原生或经核验组件，Tab/Enter/Space/Escape及选中导航按实际语义实现。关闭返回触发器，同级面板互斥，不把焦点交给后台会话。

参数/风险继承[权限业务契约](../../../../../permission-modes-contract.md)，此页只持有呈现规格。源码：[permission-picker](../../../../../../../apps/desktop/permission-picker.tsx)。现状是details＋“权限：”＋三按钮；保存/恢复已有，目标气泡、紧凑布局和状态设计未实现。

验收：三值/聚焦/悬停/开闭、保存中/冲突/确认丢失、活动Run模式不变、缩放/视口边缘；只改选项不调用模型/执行工具。权限空间是首个状态样例，不代表只修它就完成整页。
