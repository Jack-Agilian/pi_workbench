# COMPOSER 输入区

ID：COMPOSER。父：[CHAT](../README.md)。子：[PERMISSION](permissions.md)。职责是准备与提交下一任务，不是配置总面板。

| 子节点 | 位置/尺寸 | 要求 |
|---|---|---|
| COMPOSER.DRAFT | 上层全宽，最小56/上限150与高度预算取较小值 | 自动/手动增高仍有上限，之后文本区内部滚动；不随流式输出收缩/丢字 |
| COMPOSER.BAR | 下层32高，间距8 | 左侧PERMISSION，右侧发送；模型/能力说明按需，不能挤占主要动作 |
| COMPOSER.SEND | 最右36高 | 发送/加入队列/重试未确认请求准确区分；没有有效输入不能提交，原因就近可得 |
| COMPOSER.HINT | 区外底部12号短提示，非必要可按需 | 快捷键说明低权重；关键失败/未确认放区内可见，不借气泡隐藏 |
| COMPOSER.DEMO | 仅无模型演示空态的次要展开项 | 明确合成；只填草稿，不变成正式产品execute-anything入口 |

外框内边距12、圆角12，宽度跟正文共同轴线；边框/聚焦强调只围输入整体。窄窗权限与发送必要时换行而非压小文字；高度低时先收起说明，再限制文本区，保留阅读区可用。没有会话时给出新建原因；未确认请求保留原文与原身份，不自动发新的。

键盘沿用既有IME保护及Enter发送/Shift+Enter换行；不在重构中另写提交判定。草稿按Thread身份保存；权限保存未确认时不让新Run以错误模式发送。

源码：renderer composer、[composer-key](../../../../../../../apps/desktop/composer-key.ts)。现状已有草稿/排队/确认重试，输入横轴和工具栏技术标签需收敛。验收：中文输入法、长草稿、空输入、活动排队、确认丢失、切会话、低高度/200%，发送不重复。
