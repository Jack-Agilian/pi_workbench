# TOOLS 工具与审批

ID：TOOLS。父：[CHAT](README.md)，实际位于MESSAGES.RUN的操作分区。职责是理解动作、必要时决定并检查结果；审批不是独立永久侧栏。

| 子节点 | 布局/空间 | 必须显示与按需内容 |
|---|---|---|
| TOOLS.SUMMARY | 动作/目标flex，状态尾部；最小32高，行间8 | 默认动作、可辨目标、可信结果；长路径可换行，失败/待批/未知不折掉 |
| TOOLS.OUTPUT | 摘要下展开，内边距12，文本区最高220 | 参数/输出/诊断按需，长输出内部滚动；只用安全投影 |
| TOOLS.APPROVAL | 就近块，内边距12，组间8/12 | 标题 → 目标/命令 → 影响/数据去向 → 决策；长目标展开/换行，不默认截掉有意义命令 |
| TOOLS.EVIDENCE | 审批内部详情 | 文件预览、版本、权限摘要/期限等，关键影响仍在外层，不能气泡代替 |
| TOOLS.DECISION | 审批底部横排32高，间距8，窄窗可换行 | 拒绝与仅本次允许均清楚可达，期限附近；忙碌/断线禁止重复提交，保留原因 |
| TOOLS.RESULT | 同Operation原位置 | 批准不是执行完成；执行/结算/未确认用真实状态，允许后不能立即显示成功勾 |

不新增“一键批准全部”。活动快照是有效审批按钮的来源，旧历史pending只是记录；兜底与历史卡不能重复。审批消失若原按钮仍持焦则定位下一待批或输入，用户移走焦点则不抢回。长卡以阅读视口滚动为主，不能同时把目标和按钮各锁在很小滚动盒中。

源码：[approval-list](../../../../../../apps/desktop/approval-list.tsx)、run-history。现状具备宿主审批、身份兜底、结果摘要；元信息和容器视觉仍需减重。保留[权限契约](../../../../permission-modes-contract.md)的绑定、版本、期限、一次领取和固定Run模式。

验收：人工/自动/完全访问来源，允许/拒绝/过期/断线/未知、长Bash与文件预览、历史未加载、键盘焦点；折叠/动画不能执行命令或改变审批事实。
