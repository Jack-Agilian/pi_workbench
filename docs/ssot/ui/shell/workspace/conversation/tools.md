# TOOLS 工具与审批

ID：TOOLS。父：[CHAT](README.md)，普通摘要位于MESSAGES.RUN的独立操作区，当前审批占据COMPOSER上方的决策区域；可信穿插需先补宿主消息关联，不将分区永久固化。职责是理解动作、必要时决定并检查结果；审批不是独立永久侧栏。

| 子节点 | 布局/空间 | 必须显示与按需内容 |
|---|---|---|
| TOOLS.SUMMARY | 动作/目标flex，状态尾部；最小32高，行间8 | 正常历史操作默认一条组摘要，展开后按Operation显示动作/目标/结果；保留独立记录语义。失败/待批/未知在外层可见，不聚合隐藏 |
| TOOLS.OUTPUT | 摘要下展开，内边距12，文本区最高220 | 参数/输出/诊断按需，长输出内部滚动；只用安全投影 |
| TOOLS.APPROVAL | 输入区上方常驻当前待批，内边距12/14；低高度8/10 | 当前操作 → 完整关键目标/影响 → 拒绝/仅本次允许；摘要与按钮同处，长写入内容/输出通过只读详情展开，不能把整个审批埋入历史滚动；长目标展开/换行，不默认截掉有意义命令 |
| TOOLS.EVIDENCE | 由当前审批打开的只读详情面板 | 文件预览、版本、权限摘要/期限等，关键影响仍在外层，不能气泡代替 |
| TOOLS.DECISION | 决策区域底部横排32高，间距8，窄窗可换行 | 拒绝与仅本次允许均清楚可达，期限附近；忙碌/断线禁止重复提交，保留原因 |
| TOOLS.RESULT | 批准后收起决策区域，结果仍归原Operation | 批准不是执行完成；执行/结算/未确认用真实状态，允许后不能立即显示成功勾 |

不新增“一键批准全部”。活动快照是有效审批按钮的来源，旧历史pending只是记录；兜底与历史卡不能重复。审批消失若原按钮仍持焦则定位下一待批或输入，用户移走焦点则不抢回。固定审批区域保持目标、关键影响与决定可见；长证据在单独只读面板内滚动，不制造多层小滚动盒。多待批只显示当前有效项并注明剩余数，不同时堆满输入区。处理后保留草稿，不把批准当新发送。

源码：[approval-list](../../../../../../apps/desktop/approval-list.tsx)、run-history。现状具备宿主审批、身份兜底、结果摘要；当前审批独立活动快照驱动，首项+余项数；目标/风险/决定常驻，详情按需，失效时关闭，历史无决定按钮。保留[权限契约](../../../../permission-modes-contract.md)的绑定、版本、期限、一次领取和固定Run模式。

验收：人工/自动/完全访问来源，允许/拒绝/过期/断线/未知、长Bash与文件预览、历史未加载、键盘焦点；折叠/动画不能执行命令或改变审批事实。
