# CHAT 会话区

ID：CHAT。父：[WORK](../README.md)。子：[MESSAGES](messages.md)、[TOOLS](tools.md)、[COMPOSER](composer/README.md)。TOOLS管理工具摘要与审批子控件：历史摘要在所属Run，当前有效审批在输入区上方；不是第四个常驻面板，也不在两处复制可操作按钮。

垂直结构：阅读视口flex占余量 → 按需“返回最新” → 当前审批/COMPOSER固定自然高度。读区与输入使用共同最大宽及左右轴线；禁止正文全宽、输入另一套无界宽。正常工具在所属Run中提供紧凑操作摘要，待审批在输入区上方展开；现有协议仍按独立记录展示，审批即使历史未加载也有同身份兜底，不为视觉穿插伪造顺序。

v2默认阅读优先：正文14与稳定段落节奏；Run之间24间距，消息之间16，操作摘要间8。分隔只说明真实任务边界，不给每句话套卡。空态与真实记录互斥；流式增长不推动正在阅读旧记录的用户。

代码归属：renderer conversation/timeline、[timeline-scroll](../../../../../../apps/desktop/timeline-scroll.ts)。现状已有独立阅读滚动、返回最新、身份保护；输入轴线/密度待重构。父区宽变或开合动画必须与唯一滚动所有者合作，不能新增平行scrollTop恢复逻辑。

验收：空态/短回复/长Markdown/多工具/待批、加载更早与正文补读、宽度动画、用户旧位置；输入始终可见，正文不被叠层挡住，切会话两边草稿/锚点保留。
