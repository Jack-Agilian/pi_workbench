# ARTIFACTS 成果栏

ID：ARTIFACTS。父：[WORK](../README.md)。子：[PREVIEW](preview.md)。职责是找登记成果版本并核验当前文件；不承担审批、不承诺文件浏览器。

右侧位于内容带内，宽度/覆盖/收放继承共享规则；内边距12，列表独立纵向滚动。标题行sticky高40，不覆盖聚焦项。默认关闭，由显式选择打开；新成果不抢正文空间。

| 子节点 | 位置/尺寸 | 内容与动作 |
|---|---|---|
| ARTIFACTS.HEAD | 顶部40，标题flex、关闭28 | 单一标题与登记版本计数；不叠两行同义标题 |
| ARTIFACTS.EMPTY | 列表内简短空态 | 说明登记条件，不凭Bash成功伪造文件 |
| ARTIFACTS.ROW | 列表最小56，内边距8，项间4 | 图标16、文件名13、版本/核验状态12；目标优先，来源ID/字节进详情；同名时路径辅助辨识 |
| ARTIFACTS.PAGING | 列表尾32高 | 数量是已加载版本数，有后续页显示“+”，不冒充独立文件总数 |
| ARTIFACTS.NOTE | 核验详情的说明入口 | 不再每次常驻长实现解释；不匹配/缺失仍在相应条目明显展示 |

选择条目才核验并就近展开PREVIEW，旧响应不能污染新会话。关闭成果返回HEAD入口，关闭单个预览返回条目。宽度不足时文本换行/省略有完整入口，不能通过缩9px来塞下所有字段。

源码：[artifact-panel](../../../../../../apps/desktop/artifact-panel.tsx)、renderer inspector。现状：已有按需栏/版本/核验，但双标题与每行执行ID/字节/长状态平铺；目标待重排。验收：0/多版本/同名路径、核验失败/不匹配、选中分页项、开合动画和阅读位置；栏关闭不清除宿主登记。
