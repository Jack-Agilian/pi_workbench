# ARTIFACTS 文档面板

ID：ARTIFACTS。父：[WORK](../README.md)。子：[PREVIEW](preview.md)。v2职责是打开并阅读当前文档；登记列表降为切换文档的次级入口。稳定ID与目录保留，不再用成果管理列表代表整个右栏；不新增文件管理器/编辑器。

右侧位于内容带内，尺寸与专注预览规则继承共享节点。默认无对象关闭；Chat的文档入口来自已登记artifactId与Run关联，不从模型正文路径猜测文件。窄窗专注预览期间若有待审批，显示“返回处理审批”返回会话输入区；不在文档面板批准同一操作。右栏只有当前文件标题和主要内容，没有“成果与预览/成果版本/预览”三层重复标题。

| 子节点 | 位置/尺寸 | 内容与动作 |
|---|---|---|
| ARTIFACTS.HEAD | 顶部54，长名占余量；低高度44 | 当前文件名＋文档选择入口、复制、版本来源、关闭；没有常驻总版本计数 |
| ARTIFACTS.EMPTY | 用户主动打开空栏时简短空态 | “这个会话还没有文档”；不为解释登记规则常驻空栏 |
| ARTIFACTS.ROW | 文件选择面板内，名称为主、必要路径为辅 | 按路径对象查找；登记版本是对象详情。Chat关联Run下有可信文档入口，点击共用WORK选择态与原preview调用 |
| ARTIFACTS.PAGING | 选择面板列表末32高 | 复用原artifact分页；明确已加载范围，不把登记数量称为文件总量 |
| ARTIFACTS.NOTE | 正常态放来源详情；异常就近显露 | 改变/缺失/不可读不能藏进详情；不反复平铺哈希/执行ID/字节 |

PREVIEW占整个面板的剩余高度，不嵌在某一版本行下。选择、草稿与阅读状态按会话隔离；关闭面板不删除宿主登记，不清掉用户手动选择。

## 到达与打开策略

原型保留A/B比较：A为当前前台任务首次收到宿主确认的新登记文档时打开一次；B只提供Chat入口供点击。v2推荐A仅在可并排且不打扰既有阅读时使用，窄窗采用B。必须能识别本次新增与历史补页/重连；若现有投影不能可靠区分，先采用B。不能据模型“已生成”、路径存在或工具结束自动打开。

用户已打开别的文档、手动关闭，或正在旧记录/文档中阅读时，不覆盖选择/不抢焦点；后续版本只提示可主动切换。后台会话、恢复、补页不自动展开。展示不需要额外授权门槛，也不发明主文档识别字段。两种策略都是展示选择，不改变文件读取权限。

源码归属：[artifact-panel](../../../../../../apps/desktop/artifact-panel.tsx)、renderer、run-history。产品已改为独立全高阅读；[合成原型](../../../../../design/workbench-prototype/README.md)用于设计对照；产品已接入artifactId、原分页与核验，选择态和对象阅读位置由WORK持有。当前采用B：仅点击打开，未引入新到达识别字段或自动抢开。

验收：Chat→文档→切换→关闭返回、0/多文件/同名、多登记版、核验失败、旧响应、切会话/重连、用户关闭后新结果不再抢开；正文足够宽高，版本记录不伪造历史字节。
