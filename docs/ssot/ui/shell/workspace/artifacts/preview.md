# PREVIEW 文档阅读

ID：PREVIEW。父：[ARTIFACTS](README.md)。v2是面板的主要内容空间，不再位于登记条目下。顶部对象动作由父栏统一布局，正文占余量并独立滚动；不再限制260px高度。

| 子节点 | 位置/尺寸 | 要求 |
|---|---|---|
| PREVIEW.HEAD | 复用ARTIFACTS.HEAD，不新增第二标题行 | 文件名与文档本身的标题用途不同；关闭回到实际Chat入口，失效时回HEAD |
| PREVIEW.VERSION | 顶部版本/来源入口的面板中 | 只列已加载同路径登记；选择旧版仍需原核验，没有历史副本不能假装可读 |
| PREVIEW.CHECK | 正常事实放详情；异常在文件标题下 | 核验中/一致/改变/缺失/不可读/请求失败分开；上次一致不是实时保证；失败不留旧正文冒充新选择 |
| PREVIEW.CONTENT | 余量全部用于阅读；左右28，文档正文继承FOUNDATIONS | 安全Markdown阅读优先，复用现有展示组件前核对过滤边界；代码/表格局部滚动。不执行HTML、加载远程图片或开放任意文件 |
| PREVIEW.COPY | 顶部28次动作＋名称/提示 | 复制上次核验的展示文本；过滤文本不用于重算原文件摘要；产品桥约束不因原型剪贴板改变 |
| PREVIEW.SOURCE | 版本/来源面板中 | 完整路径、Run/Operation/hash按需；可定位来源但不变成自由路径读取；不承诺原型尚未覆盖的真实跳转 |
| PREVIEW.RECHECK | 错误旁显式动作，正常时来源内次动作 | 只核验已有对象，不重写/恢复文件；匹配失败不能被“刷新”掩盖 |

打开当前文件只用一个选择态和一次核验接缝。关闭使旧响应失效；切版本先显示新对象加载/错误，不用上一个版本正文占位冒充成功。自动展示不转移焦点；用户显式打开可将焦点移入面板，关闭回入口。选择/阅读位置在本次应用中随会话和对象保存（不持久化文件正文），连接代次仅保留选择意图，重新核验，不复用旧ready状态。

原型没有额外常驻阅读/源文模式栏；需要源文时以后放次级入口，不能为预览添加工具带。产品源码：[artifact-panel](../../../../../../apps/desktop/artifact-panel.tsx)；现有读取/复制边界见[阅读动作契约](../../../../reading-actions-contract.md)。产品已按v2复用MessageMarkdown，未知/改变/缺失均不显示旧正文；实际磁盘验证和合成展示分别记录。

验收：长正文/路径、小窗/200%、核验状态、迟到响应、部分版本、关闭/返回、同路径新版本提醒不跳走阅读；不把截图或合成状态当真实磁盘/IPC验证。
