# PREVIEW 成果预览

ID：PREVIEW。父：[ARTIFACTS](README.md)。是选中条目下的就地子空间，不另弹全屏编辑器。宽为父内区，内边距12，段间8；不再给每段嵌套卡片。

| 子节点 | 位置/尺寸 | 要求 |
|---|---|---|
| PREVIEW.HEAD | 首行标题flex、关闭28 | 文件名＋版本；长名换行，关闭仍可达 |
| PREVIEW.VERSION | 下一行32高选择器 | 标明已加载同路径版本；未完整加载就说明，不伪造历史副本 |
| PREVIEW.CHECK | 版本下状态12号、自然高度 | 核验中/一致/改变/缺失/不可读/请求失败准确区分；上次时间不是实时保证 |
| PREVIEW.CONTENT | 后续全宽等宽13，最大高260再局部滚动 | 只有匹配且安全的预览文本；长行可换行，内容为空与未加载不同 |
| PREVIEW.COPY | 内容前后明确次动作28 | 复制上次核验的展示文本；过滤后的文本不能重算登记原字节摘要 |
| PREVIEW.SOURCE | 详情展开，完整路径/Run/Operation/hash | 来源只读，不能跳成任意文件读取；字段长串可断行 |
| PREVIEW.RECHECK | 末尾32高次动作 | 显式重新核验，不自动重写或恢复文件 |

切版本只读核验，失败不显示上一版本正文冒充当前；关闭使旧响应失效。选中时合理聚焦预览，重复轮询不抢焦点，关闭返回原条目，原条目不可用时返回列表入口。展开内容即时或轻淡入，不用自动高度动画反复推动长列表。

源码：[artifact-panel](../../../../../../apps/desktop/artifact-panel.tsx)。现状上述身份/核验流程已存在，目标是层级与控件密度；原读取/复制边界仍由[阅读动作契约](../../../../reading-actions-contract.md)持有。

验收：匹配/改变/缺失/不可读/网络失败、迟到响应、部分版本、长路径/正文、关闭返回；动画不重复核验，核验不写文件。
