# FEEDBACK 配置与情境反馈

ID：FEEDBACK。父：[WORK](README.md)。这是一组按需空间，不是永远占位的仪表盘。位于顶部下方；单行提示最小32，动作32高，内边距8/12，文字可换行。标准无异常且配置就绪时不常驻大配置块。

| 子节点 | 展示与布局 | 不能混淆的事实 |
|---|---|---|
| FEEDBACK.MODEL | 未就绪时展开配置引导；就绪后的模型名称归COMPOSER的紧凑入口，具体信息按需展开 | 仅公开产品字段，凭据值不进入页面；现有私有文件选择仍由宿主处理；预算兼容状态不能变为默认产品额度 |
| FEEDBACK.CONNECTION | 顶部就近持久错误＋重连动作 | 与普通读取失败不同，重连有结束旧宿主未完成任务的后果，说明必须可读 |
| FEEDBACK.READ | 所属读取区域错误＋只读重试 | 刷新不重启宿主、不重发操作，保留已显示内容 |
| FEEDBACK.OTHER_RUN | 不在当前会话的活动任务摘要＋返回/停止 | 目录过滤不使原执行失联，不增加另一套调度或永久并列停止 |
| FEEDBACK.RECOVERY | 清理/副作用未核实时的阻断原因与核验入口 | unknown不称成功；恢复核验不重做副作用 |
| FEEDBACK.TERMINAL | 对应任务旁必要的终态反馈；普通成功由回答/文档承接，失败/取消/未知明确 | 历史初读/重连不重播；状态取宿主最终结算 |
| FEEDBACK.WORKSPACE | 当前目录不可用的原因 | 阅读仍可用，不能默默切目录继续原任务 |

多项同时出现按阻断影响排列：连接/恢复 → 当前配置/目录 → 跨会话执行 → 普通完成。相关原因可合并呈现但保留各自动作语义；不能全部轮播。低高度/200%时次要解释可展开，反馈带超过可用高度四分之一时局部滚动并保持首要动作可见；正文和输入必须仍可达。

出现/消失不使用toast滑过正文；状态反馈及时，避免对轮询内容每次重放动画/朗读。焦点已在错误动作上时，错误解除需合理接续，不抢用户已移走的焦点。危险后果不能藏于气泡。

源码：renderer model-settings/notice、[other-runs](../../../../../apps/desktop/other-runs.tsx)、[run-status-notice](../../../../../apps/desktop/run-status-notice.tsx)。现状：就绪模型只保留输入栏名称入口；配置按需，连接/跨会话/终态/恢复信息合计最多25vh滚动。运行结果的权威来源不变。验收：所有上述状态单独及组合、长错误、低高度、迟到成功/断线；不因为收起提示改变业务状态。
