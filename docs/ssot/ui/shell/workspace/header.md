# HEAD 会话顶部

ID：HEAD。父：[WORK](README.md)。职责是当前对象、导航与即时执行动作；不承担长配置说明。高度/留白继承共享参数，横向顺序稳定。

| 子节点 | 位置/大小 | 要求 |
|---|---|---|
| HEAD.NAV | 最左32命中框 | 导航开关，当前展开状态可感知；收起后仍在同一位置 |
| HEAD.IDENTITY | 中间flex，min-width:0 | 标题16主行、必要目录12辅行；长名省略，完整内容有可达入口，空会话不用伪标题 |
| HEAD.ACTIONS | 右侧，32高控件，间距8 | 待批（情境出现）、停止（活动时）、成果开关、更多；停止不收进更多菜单 |
| HEAD.CONTEXT | 更多的相邻浮层，宽288，上限视口减24 | 当前运行模式/目录/边界按需；长说明内部滚动，不重排顶部 |

普通状态只露出必要入口，审批数量到达时就近出现但不主动滚走正文。窄窗允许标题与动作分两行；先收起辅助目录及次要说明，不能缩小到不可读。成果入口用“成果”及展开状态，避免“详情”无法判断内容；这是目标文案，当前仍为查看/隐藏详情。

关闭弹层返回触发点，Escape遵循最上层；上下文不是模态，不锁住整页。停止只来自宿主可取消状态，不把“请求已接受”写成“执行结束”。

源码：renderer thread-heading/context-details。现状：有独立审批/停止与更多；用title补充路径，尚不能当键盘气泡完成。验收：长标题、0/多审批、正在停止、成果开合/窄窗；固定动作可发现、无重叠，打开上下文不影响执行状态。
