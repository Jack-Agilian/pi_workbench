# HEAD 会话顶部

ID：HEAD。父：[WORK](README.md)。职责是当前对象、导航与即时执行动作；不承担长配置说明。高度/留白继承共享参数，横向顺序稳定。

| 子节点 | 位置/大小 | 要求 |
|---|---|---|
| HEAD.NAV | 最左32命中框 | 导航开关，当前展开状态可感知；收起后仍在同一位置 |
| HEAD.IDENTITY | 中间flex，min-width:0 | 标题14主行、必要目录12紧凑身份入口；长名省略，点击标题改名，完整目录在会话信息可达，空会话不用伪标题 |
| HEAD.ACTIONS | 右侧，32高控件，间距8 | 停止（活动时）、文档开关、更多；取消顶部待审批跳转按钮，单次决策集中在输入区。停止不收进更多菜单 |
| HEAD.CONTEXT | 更多的相邻浮层，共享宽380，上限视口减24 | 当前Thread实际目录、当前Run固定模式与后续模式分别按需；长说明内部滚动，不重排顶部 |

普通状态只露出必要入口，待审批在输入区主动出现但不滚走正文。窄窗允许标题与动作分两行；先收起辅助目录及次要说明，不能缩小到不可读。文档入口使用文件图标＋“打开文档”名称/提示及展开状态，避免“详情”无法判断内容；这是目标文案，当前仍为查看/隐藏详情。

关闭弹层返回触发点，Escape遵循最上层；产品上下文优先轻量可关闭面板，原型用原生dialog演示焦点返回；不能把原型模态实现写成产品已完成。停止只来自宿主可取消状态，不把“请求已接受”写成“执行结束”。

源码：renderer thread-heading/context-details。现状：顶部移除审批跳转；停止保留，当前目录/上下文以原生dialog展开，文档图标入口和标题改名分别委托原所有者。title仍只是辅助提示，不据此宣称所有图标已有自定义可访问气泡。验收：长标题、0/多审批、正在停止、成果开合/窄窗；固定动作可发现、无重叠，打开上下文不影响执行状态。
