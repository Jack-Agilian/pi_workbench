# 共享尺寸与视觉参数

ID：FOUNDATIONS。归属：[规格树](README.md)。以下是v2设计候选，以CSS px计；依据[原型](../../design/workbench-prototype/README.md)检查，不是产品已实施或竞品标准。窗口外框/系统标题栏不计入内容尺寸，缩放以实际CSS视口计算。

## 空间预算（v2）

| 参数 | 目标与理由 | 当前产品差距 |
|---|---|---|
| 导航宽 | 默认232，200–300可调；低于760视口时用可退出的覆盖导航，宽不超过280及视口减44 | 现有224/180/360与700断点待统一；不重写已有拖宽所有者 |
| 文档宽 | 默认440，360–620可调；文档正文需要连续阅读空间，不能沿用元数据列表的328默认 | 当前328/280/640；预览仍嵌于条目下 |
| 会话保底 | 并排时448；可用宽不足就切换内容带内的专注预览。预算=视口−实际可见导航−文档宽；不能只检查固定1000断点 | 当前360与固定断点需调整；拖宽越界时优先限制尺寸，不让拖动中突然失去分隔条 |
| 阅读/输入轴线 | 共用最大760，标准两侧28，窄窗16；输入外框与正文左沿相同，不算输入内部padding | 当前正文840，输入未共轴；原型已演示相同轴线 |
| 顶部 | 常态64、窄窗56、低高度48；允许必要换行，停止优先于辅助目录 | 当前自然高度；具体长名组合仍需产品复验 |
| 输入 | 文本区最小54、上限160且不超过CSS视口高25%；低于520高时36–70；工具栏32、底部12–20 | 沿用IME/草稿/提交所有者，只改空间分配 |
| 控件 | 常用32，紧凑图标最小28×28，图形16；文字动作不为了统一宽度裁切 | 已有多套padding待收敛；32不是无障碍认证 |
| 字级 | 会话14/1.8、操作13/1.55、辅助12/1.55、会话标题14、文档正文14/1.85、文档标题25 | 文档阅读与操作界面密度不同；不使用9–10px塞业务说明 |
| 间距/圆角 | 间距4/8/12/16/24/28/32；普通6、浮层12、输入13；按角色复用 | 原型值作为一组候选，实施时集中token，不逐组件任意新增 |

颜色使用正文、辅助、边界、选中、警告角色；原型为暖白/中性灰与低饱和绿，只把待批/故障用警告色。字体为系统栈，不远程加载字体。MD文件徽标可小于正文，但关键说明不可随之缩小。

## 响应与溢出

默认232导航+440文档+448会话至少需1120CSS宽；1320宽的会话为648。导航收起或用户改宽后按实际预算重新计算，不同时维护另一套CSS阈值。视口不足时右侧占据内容带，顶部停止/导航仍可达；不是全应用模态，不应虚假声明aria-modal。小于760时导航覆盖整个工作台，主区不可交互。

正文与文档各自滚动，输入固定在会话底部；文档无260px上限。代码/表格仅自身横向溢出，长路径换行或提供完整入口。低高度先移除装饰留白和普通说明，反馈限制高度，不能挤没发送/停止/错误恢复。原型控制条不属于产品预算。

现有Electron外框1320×900/最小820×640不在本批修改；200%时仍需按CSS宽高适配。此次检查属于原型渲染，具体屏幕阅读器、触摸命中和产品性能另验。
