# 产品术语

| 内部对象 | 用户称呼 | 边界 |
|---|---|---|
| Workspace | 工作区 | 已批准目录和权限范围 |
| Thread | 会话 | 多条消息和多次执行的长期容器 |
| Pi Session | 原生会话 | Pi 所有的历史和上下文，不另建消息树 |
| Message | 消息 | 用户、助手或工具内容 |
| Run | 一次执行 | 一个已接受输入及其模型/工具循环，允许零工具 |
| Operation | 工具操作 | 独立身份、授权、结果和审计 |
| Task | 业务任务/目标 | 用户业务语义；本轮不新增 Task 表 |
| Worker | 执行进程 | 可每 Run 回收，不删除原生会话 |

改文案不改数据库对象和 requestId 幂等语义。相同内容的两次明确发送是两个请求。M1 保持独立 Run 队列，不同时投递 Pi followUp。
