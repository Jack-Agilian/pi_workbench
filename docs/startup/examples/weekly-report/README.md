# 周报示例包

这是文档配套的内容型本地草案，没有可执行脚本或 npm 安装命令。`workbench.plugin.json` 是自有格式；`package.json.pi` 演示 Pi 资源声明。

未在 Pi 或 macOS/Windows 运行验证。`declaredPlatforms` 是目标声明，`verification: unverified` 禁止展示“已兼容”徽章。公开发布前必须明确正式许可证、做样例测试、签名并经过审核。`LicenseRef-Local-Draft` 不是公开许可授权。

安装不等于授权；manifest 中的能力只是申请。整个安装器和能力约束需由产品实现。
